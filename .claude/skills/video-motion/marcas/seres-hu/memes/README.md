# Biblioteca de memes do Seres HU

1. Salve aqui o arquivo do meme (ex.: `macaco-pensando.jpg`).
2. Registre em `memes.json`, por exemplo:
   `{ "arquivo": "macaco-pensando.jpg", "tom": "confusao", "usar_em": "curiosidades, coisas anormais, entretenimento", "descricao": "macaco com a mão no queixo, pensativo" }`
3. Nos vídeos, a cena `meme` usa `"imagem": "memes/macaco-pensando.jpg"`.

Só use memes de que você tem direito, ou que sejam de uso livre. Memes com foto de pessoa comum (principalmente crianças) não entram.
